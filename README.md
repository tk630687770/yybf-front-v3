# 双色球选号工具

## 项目简介

前端本地持久化方案，采用 IndexedDB 存储后端数据，支持离线展示。本项目用于双色球（红球33个+蓝球16个）选号分析，提供了窗口等级统计、号码联动选择、模拟模式等功能。

## 技术栈

| 技术 | 用途 |
|------|------|
| Vue 3 + Composition API | 框架 |
| Vite | 构建工具 |
| TypeScript | 语言 |
| Dexie.js | IndexedDB 封装 |
| Pinia | 状态管理 |
| Vue Router | 路由 |
| Tailwind CSS | 样式（暗色主题） |

## 功能特性

### 1. 开奖信息展示
- 显示最新一期开奖结果
- 包含红球、蓝球、尾数、质数等信息
- 支持数据初始化和刷新功能

### 2. 窗口等级统计
- 12种窗口类型：红球10/20/33、蓝球10/16/32、红尾10/20/33、蓝尾10/16/32
- 表格展示等级、号码、出现次数、比例、索引等数据
- 支持热力图颜色渲染

### 3. 号码选择与联动
- 左键点击增加状态（0→1→循环结束）
- 右键点击减少状态（1→0→-1→循环结束）
- 相同球色球种的窗口之间号码状态联动
- 状态：-1（排除/灰色）、0（未选/透明）、1（已选/红色）

### 4. 模拟模式
- 开启后根据 willDown 值计算模拟位置
- 号码位移受上移限位控制
- 降级标识（⬇️）颜色随位置变化

### 5. 选择数据统计
- 实时统计已选/排除的红球、蓝球、红尾、蓝尾
- 显示奇偶质数量统计
- 去重显示，同一号只显示一次

### 6. 数据管理
- IndexedDB 本地持久化存储
- 支持窗口数据和统计数据独立存储
- 窗口状态弹窗管理各窗口数据更新

### 7. 历史回放实验
- 支持按开奖前视角运行历史期号回放
- 支持保存和读取历史回放实验
- 展示收益、红球命中、蓝球命中、奖级分布和逐期明细
- 支持两个已保存实验横向对比，用于比较正式基线和观察策略
- 用于验证策略版本，而不是替代开奖前快照复盘

### 8. 红球入口召回研究
- 独立研究第一层入口池能否在Top15/18等规模内保住真实红球
- 支持独立组件、组合算法、入口规模和历史范围参数
- 支持正式实验保存、横向对比、逐期逐球证据和时间切片稳定性
- 支持两两组件与权重网格预览，临时网格结果不自动落库
- 与最终票面历史回放分离，入口策略稳定前不进入正式预测

| 球种 | 枚举 |
|------|------|
| 红球号码 | RED_NUMBER_10, RED_NUMBER_20, RED_NUMBER_33 |
| 蓝球号码 | BLUE_NUMBER_10, BLUE_NUMBER_16, BLUE_NUMBER_32 |

## 号码状态说明

| 状态值 | 含义 | 背景色 |
|--------|------|--------|
| -1 | 排除 | 灰色 |
| 0 | 未选 | 透明 |
| 1 | 已选 | 红色 |

边框颜色根据 previousRec 值确定：0（透明/白色）、1（黄色/命中）、2（紫色/邻号）。

## 行列折叠功能

### 功能概述
- 支持以等级为单位的行折叠（4个子行作为一个折叠单元）
- 支持以列为单位的列折叠
- 模拟模式下自动展开包含球的折叠区域

### 操作方式

#### 行折叠
1. **选择等级**：左键点击等级格可选中/取消选中高亮显示的等级
2. **折叠选中**：右键点击已选中的任意等级格，弹出菜单选择"折叠"
3. **展开单个等级**：右键点击已折叠行，弹出菜单显示已折叠的等级列表，点击可单独展开
4. **展开全部**：右键菜单中选择"展开全部"可展开该折叠区域的所有等级

#### 列折叠
1. **选择列头**：左键点击列头可选中/取消选中
2. **折叠选中**：右键点击已选中的列头，弹出菜单选择"折叠"
3. **展开**：右键点击已折叠区域，弹出菜单显示已折叠列索引，点击可展开

### 折叠范围合并
- 相邻的折叠区域会自动合并
- 选择包含已有折叠区域的等级时，会自动合并为一个折叠范围
- "加入折叠"功能可将单个等级加入相邻的折叠区域

### 自动折叠规则
- 页面初始化时自动折叠空行（没有球的等级）
- 页面初始化时自动折叠空列（所有等级都没有球的列）
- 只折叠没有数据的区域，保留有球的区域

### 模拟模式联动
- 开启模拟模式时，自动展开所有包含降级后球的折叠行和折叠列
- 升降级操作触发折叠区域自动展开
- 联动变化也会触发相关分栏的自动展开

### 分栏模式
- 同类型窗口自动合并分组显示（如红球10/20/33合并为一个标签）
- 分栏模式下每栏有独立的折叠状态
- 各栏之间保持号码联动同时拥有独立的行/列折叠状态
