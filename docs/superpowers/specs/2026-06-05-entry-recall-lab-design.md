# 红球入口召回研究台设计

日期：2026-06-05  
状态：已确认，进入实施

## 1. 页面职责

新增独立路由 `/entry-recall-lab`，专门承载红球入口池召回专项研究。

它与现有页面的边界：

- 不进入 `/prediction-console`：入口实验不改变正式预测。
- 不进入 `/snapshot-review`：入口实验不是开奖前快照复盘。
- 不进入 `/diagnostic-lab`：入口专项具有独立实验表、组件组合和逐球证据，信息量超过普通诊断区。
- 不合并进 `/historical-replay-lab`：历史回放台关注最终票面和收益，入口召回台关注Top15/18等入口池是否保住6个真实红球。

## 2. 页面目标

让研究者能在一个页面完成：

1. 配置独立组件、组件权重、标准化方式、组合算法、入口规模和历史范围。
2. 运行临时预览或正式保存实验。
3. 查看平均命中、0至2红、至少4红、至少5红、完整6红和随机完整6红基线。
4. 查看逐期入口池、命中、遗漏、边界号码和最近遗漏号码。
5. 查看逐球最终排名、组件评分、组件排名和淘汰原因。
6. 查看已保存实验列表、详情、横向对比和连续时间切片稳定性。
7. 运行两两组合与权重网格预览，筛选值得正式保存的候选。

## 3. 页面结构

页面按研究流程从上到下排列：

### 3.1 研究边界与操作区

- 明确显示“严格开奖前视角”和“只用于入口召回研究”。
- 提供运行预览、运行并保存、刷新实验列表按钮。
- 显示运行状态、错误和重复指纹提示。

### 3.2 实验参数区

- 组件列表采用可增删行，每行包含组件、权重、标准化方式和配额。
- 组合算法支持：
  - `WEIGHTED_SUM`
  - `RANK_VOTE`
  - `QUOTA_UNION`
- 配额并集选择后显示目标规模和每组件配额。
- 入口规模使用逗号文本输入，默认 `15,18,20,22,24`。
- 历史范围支持起止期号和最近期数。

### 3.3 当前实验摘要区

- 展示实验编码、版本、有效期数和耗时。
- 用统一表格横向展示各入口规模指标。
- 用命中分布徽标展示0至6红期数。
- 明确提示随机完整6红基线和提升倍数。

### 3.4 逐期与逐球证据区

- 逐期表格展示期号、入口规模、入口池、命中、遗漏、边界号码和最近漏号。
- 点击逐期行后，逐球证据表只展示对应期号。
- 逐球表展示最终排名、最终分、是否开奖、进入哪些入口规模、淘汰原因和组件证据。
- JSON组件证据在前端解析为简洁文本，不直接展示原始JSON。

### 3.5 已保存实验与稳定性区

- 列表展示ID、名称、策略、范围、有效期数、耗时和创建时间。
- 点击详情读取不可变正式实验，不重新计算。
- 点击稳定性按默认4个连续区间读取，不重新运行组件。
- 稳定性表展示各入口规模的跨区间波动和首末区间变化。
- 支持选择2至10个实验读取对比；第一版重点显示主表配置和组件指标，不做复杂图表。

### 3.6 两两矩阵与权重网格区

- 独立折叠区域，默认收起，避免干扰主实验流程。
- 允许选择多个组件、算法和预设权重向量。
- 返回候选编码及各入口规模核心指标。
- 网格结果只预览；选中方案后由用户复制参数到正式实验区再保存。

## 4. 前端结构

新增文件：

```text
src/api/modules/entryRecall.ts
src/views/EntryRecallLab.vue
src/components/lottery/entry-recall/
├── EntryRecallExperimentForm.vue
├── EntryRecallMetricTable.vue
├── EntryRecallEvidencePanel.vue
├── EntryRecallExperimentList.vue
├── EntryRecallStabilityPanel.vue
└── EntryRecallGridPanel.vue
```

页面只负责接口状态和区域编排；参数编辑、指标、证据、列表、稳定性和网格分别由组件负责。

## 5. 数据与错误处理

- 后端响应继续使用现有Axios封装。
- 实验运行和网格预览超时设置为5分钟。
- 正式实验列表、详情、对比和稳定性读取使用默认60秒。
- 空结果、重复实验、参数错误和网络错误都在页面头部显示明确中文提示。
- 页面不在IndexedDB保存入口实验，正式证据以后台专用实验表为唯一来源。

## 6. 验证

- 执行 `npm run build`。
- 启动前后端后验证：
  - 页面路由和顶部导航。
  - 预览实验。
  - 正式实验列表和详情。
  - 逐期选择后逐球证据切换。
  - 实验ID=2的稳定性读取。
  - 两两权重网格预览。
  - 浏览器控制台无相关错误。

## 7. 设计取舍

- 第一版不引入图表库，优先使用表格、徽标和颜色，减少新依赖。
- 第一版不允许网格结果一键正式保存，避免未经阅读的参数组合直接进入正式实验表。
- 第一版不在前端定义策略准入阈值，只展示后端客观指标和时间切片证据。
- 页面完成不等于策略有效；策略结论仍由阶段6的100期系统研究产生。
